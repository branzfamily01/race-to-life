# Race to Life

車が好きな子ども向けの、勉強・片付け・学校準備を1つのレーシングゲーム世界にまとめたPWAです。

## モード
- 📚 STUDY: 1分 = 10pt の学習タイマー
- 🧹 CLEAN UP: 天国と地獄（アプリ内シンセ演奏）＋片付け個数カウンター＋自己ベスト
- 🎒 PREP: 学校・明日の準備チェック＋5分チャレンジ

## ゲーム要素
- 11車種の個別画像
- 12種類のサウンドコレクション
- パーツ収集
- ボーナスレース券
- 曲がりの強い3D風レース
- 3モード達成でDAILY GRAND SLAM
